# Slackメッセージをカードの資料として扱う

Slackの会話から仕事を切り出し、あとから追加の依頼を同じ仕事に集められるよう、メッセージは既存のタスクカード・セッションカードが参照する資料とする。メッセージとカードは多対多で関連付け、会話の全メッセージをタスクカードに変換したり、1メッセージを1カードに限定したりはしない。

仕事の根拠を確認できるよう、履歴はカードに紐づけたメッセージだけを対象にし、Slack側で削除されても保存済み本文を保持する。全会話の履歴保存や、Slackの現在の状態だけを表示する方式は選ばない。履歴にはCanbanが取得・受信できた内容だけを記録でき、未接続中の全変更の復元は保証しない。

Slack参照は、エージェントのセッション紐づけとは別の関係である。最後のSlack参照を外した後の履歴保持と、資料をエージェントへ渡す際の版の選択は、続く設計で決める。
