# ライフタイムラインの構想用語

以下は検討中の用語であり、現行Canbanの実装済み概念とは区別する。

**ターゲット**：望む変化、達成したいこと、または維持したい状態。期限や終点を持たなくてもよい。カテゴリやAIの実行先とは異なる。

**ターゲットライン**：一つのターゲットについて、望みと、それに関わる取り組みや記録を時間に沿って見る行。

**課題**：ターゲットに向き合うための問い・取り組み。複数のターゲットに貢献し得る。

**行動**：実施や完了を確かめられる仕事の単位。既存のタスクカードを利用する。

**時空間記録**：行動・出来事・判断を「いつ、どこで」とともに表す一つの記録。計画、実績、仮説を区別する。点または期間を持ち、時期・場所が不明の場合もある。

**場所文脈**：ある期間に関わる場所、滞在先、移動、またはオンラインの場。本人の所在地と、仕事の対象場所を区別する。

**貢献関係**：同じ課題や行動がどのターゲットに関わるかを示す関係。達成率、金額の配賦、権限の継承を意味しない。

**コスト記録**：時間・金額などの投入量について、値、単位、負担主体、見積か実績か、出所を持つ記録。不明と0を区別する。

**参照ドット**：複数のターゲットラインから同じ時空間記録を辿るための表示。別の実績や別のコストを作らない。

**意味ズーム**：縮尺に応じて、個々の記録、課題の束、章や領域へ表示の粒度を変えること。
