[12画面の比較](index.html)。1280×800、ボード／時間軸×横展開／中央3枚／重ねる×ライト／ダーク。ホバーはhover-light.jpg。

レイヤー2。会話の受信元は左、送信先は右へ開く。Shift+1/2/3と⌘Kでビュー切替。Escは1訪問戻り、Shift+Escは進む、Shift+Homeは起点。上位ポップオーバーや入力離脱は既存優先。

同じセッションのDOMは1つを再使用する。再訪を経路チップで残し、訪問位置ごとのスクロールとセッション単位の下書きを保つ。routeは非保存、ビューのみ共有。

実機確認：A/B/Cを実クリックで切替後もカードが開いたまま。ホバーの一時表示からポップオーバーへ移動、クリック固定してマウスを離しても表示維持。コンソールエラーなし。
