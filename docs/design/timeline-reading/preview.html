提案のポイント

  1. 1右側は「カードそのもの」。別のプレビュー部品をやめ、カード詳細（スレッド型）を時間軸の右にそのまま開く。見出し・属性の1行・会話・入力欄・詳細パネル d がオーバーレイと同じ。Enter は「大きく開く」（オーバーレイ）に。
  2. 2まず要点。表示の 1 テキスト / 2 プレビュー / 3 要点 をここでも使え、先頭に「結果・確認済み・残り」を出す。長い報告を全部読まなくても状況がわかる。
  3. 3自動化の指示は1行に畳む。heartbeat のような長い定型の指示（XMLタグ込み）は「⚡ 自動化の指示」として畳み、押すと展開。人の発言は右寄せの吹き出し、エージェントは枠なしの本文で、誰の発言かが一目でわかる。
  4. 4読みやすい本文。16px・行間1.8・本文幅42remを守り、パス・ハッシュはコード体で折り返す。日付の区切りを入れる。左右の余白に本文が押し込まれない。
  5. 5キーの案内は全画面で1部品・1か所。置いた場所の分だけボードを押し出し、カードを覆わない。ボード・時間軸・カードを開いた状態のどれでも同じ「キーの案内」を同じ位置に出す。中身だけが文脈で変わる。見出しをドラッグして 右上・右下・左下・下端の帯 に移せ、位置は共有 UI 状態に保存（矢印キーでも移動、– で畳む）。
  6. 6一覧の幅もドラッグで。時間軸の一覧と右のカードの境目をドラッグして幅を変えられる（カードの幅と同じく保存）。
