## C1 会話の高さ

時間軸で「README 修正」を開いた直後の実測（ドッキング、カード 724×724）。ライトとダークで同じ値。

| 部分 | 前回 | 今回 |
|---|---|---|
| カード見出し | 108px | 90px |
| タイトル | 33px | 33px |
| 状態の行 | 28px | 30px |
| 会話 | 241px | 398px |
| 質問＋入力欄 | 287px | 174px（質問 36px、入力欄 107px） |

- 拡大（カード 1248×720）: 見出し 40px、会話 444px、質問＋入力欄 174px。前回の会話は 265px。
- 質問を開いた状態: 質問 140px、会話 294px。

Codex の計測（194〜202px → 426px）とは別の数値である。こちらの 398px は、サイドバーを開き、親タスクのパンくずがある状態の値。差の 28px は、下の R1（見出しの折り返し）でほぼ説明できる。

確認できたこと:

- 質問は「質問 検証方法を選んでください 選択肢 2」の1行で残る。クリックでも、フォーカスして `Enter` でも開閉できた。
- 開くと質問文、選択肢「実機」「架空データ」、案内「元アプリで答えます。ここから回答・承認は実行しません。」が出る。押せる回答ボタンはない。
- ⌘K の「質問と選択肢を開く / 閉じる」でも開閉できた。
- 下書き「再評価の下書き xyz」、キャレット7文字目、読む位置（scrollTop 5000）は、質問の開閉、拡大、ドッキング、関連先「ログイン修正」への移動と「前のカードへ戻る」のあとも同じだった。一覧の選択も「README 修正」のまま。

### R1 見出しが1行にならない（ドッキング時）

親タスクのあるセッションをドッキング幅 724px で開くと、見出しは 90px で、パンくずが縦に3段になる（「受信箱 ▾」／「/ 決済フォームの検証」／「⇧→」）。

- パンくずの枠は幅 127px に縮み、中の `.card-list-controls` は幅 0 で高さ 80px。その右に同じ幅 127px の空き（`.grow`）が残っている。場所が足りないのではなく、空きの配分の問題に見える。
- 親タスクのない「調査」のカードと、拡大時（40px）は1行に収まる。
- 1行になれば会話は約 50px 増え、Codex の 426px を上回る見込み。

再現: 時間軸 →「README 修正」を選ぶ。証拠 [01-c1-docked-light.jpg](evidence/completion-followup/01-c1-docked-light.jpg)。

あわせて、この幅では「思考」「変更」「ターミナル」「詳細」がキーの文字だけになる（`y` `f` `t` `d`）。「思考」にはアイコンもない。名前は `title` にだけ残る。

## C3 `Esc` で戻る

## C6 照らしと小片

| 操作 | 結果 |
|---|---|
| 小片 → ポップアップで「動いている」にポインターを置く | 行が薄くなり、小片は「期間 30日 · 照らし中 動いている」 |
| そのまま `Esc` | ポップアップが閉じ、薄い行は元に戻り、小片は「期間 30日」。プレビューは残らない |
| 開き直して「動いている」をクリック | 照らしが固定され、小片と一致 |
| `Esc` 1回目 | ポップアップだけ閉じる。照らしと小片は残る |
| `Esc` 2回目 | 照らしが解除され、小片は「期間 30日」。カードは閉じない |
| 小片 → `p` で固定 | 帯が固定される。照らしは始まらない |

ライトで全行、ダークでクリック以降の3行を確認した。前回の状態（小片が古いまま、`Esc` で解除されない）は再現しなかった。前回と完全に同じ操作履歴だったとは言えないので、「再現せず」と記録する。フォーカスだけで照らす経路は確認していない。
