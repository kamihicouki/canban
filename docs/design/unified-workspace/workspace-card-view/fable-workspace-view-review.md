## 重大な残課題

### 1. 2列にすると、置き方の切替（`v`）が効かない見込み [差分]

`.pane-layer[data-shape="workspace"] .card-board-viewport { inset: 0 }` と `.pane-row { width: 100% }` が、スプリットの指定（`inset: 0 16px 12px 42%`、`ui/card-overlay.css:67`）と同じ強さで後ろに書かれている。2列ではカードが常に画面いっぱいになり、スプリット（ボードを左に残す）は見た目が変わらないはず。

- 設計は「形と置き方を分ける」だった。今は 2列＝全画面の1通りになっている。
- キーの一覧には `v` が「配置切替」として残る。押しても変わらないキーになる。
- カードの幅と高さの調整も 2列では消してある（つまみを非表示）。
- 画面では確かめていない。スプリットと シート の画像が無い。

求めること: 2列でスプリット・シートを選んだ画像を撮る。効かないなら、効かせるか、2列のあいだは `v` を一覧から外して理由を書く。

### 2. 左の列の上半分を道具が使い、起点・関連が下へ押される [画像]

`board-light-session-workspace` で、左の列（約280px、高さ約760px）の使い方:

- 上の約340px: 切替の2ボタン、題名2行、道具が5段（Claude で答える／思考・変更／ターミナル・詳細／×）、パンくず、属性2行。
- 起点は y≈385 から、最新の発言は y≈480 から、関連の見出しは y≈615。関連の中身は画面の下端で切れている。

この列の役目は「起点・関連・現在地がいつも見える」ことで、今は道具置き場が主になっている。窓が低いと起点も隠れる。

求めること: 道具を1〜2段にまとめる（ラベルを畳んでアイコン＋キーにする、× は切替の段へ）。題名の下にすぐ起点が来る順にする。1280×800 で関連の1件目まで見えることを受入に足す。

### 3. 細い帯のボタンが2行に折れる [画像]

`timeline-light-session-workspace`（カード幅676px）と `narrow-700-context-closed` で、「文脈」「起点」「最新」「カード型」が1文字ずつ縦に折れ、帯が約45pxになっている（指定は30px）。題名が長いと起きる。`gantt-dark-task-workspace` は題名が短く、折れていない。

求めること: `.ws-compact .ws-control` に折り返さない指定と縮まない指定。帯の高さを長い題名で計る。

### 4. タスクの2列は、中身が整理されていない [画像・差分]

`board-light-task-workspace` と `gantt-dark-task-workspace`:

- 左の「起点」はタスクの説明で、右の「目的・説明」と同じ文が同時に2か所に出る。
- `s` は説明ではなく会話の区画へ動く（`jumpWorkspaceOrigin` のタスクの分岐）。見出しと行き先が合っていない。
- 左の「最新の発言（観測）」が「最新の報告・次の行動は未取得です」で、右には担当会話の最終返答が出ている。報告と発言を同じ見出しで呼んでいるので、取れているのか取れていないのか読めない。
- 下の「新しいセッションを開始」が約230px（画面の約3割）。前回の指摘7のまま。

求めること: タスクでは見出しを「目的」「最新の報告」にし、`s` は説明へ。開始の入力欄は、フォーカスが無く空のとき実行先の行と注意書きを畳む。

### 5. 前回からの持ち越しが、今回も確かめられていない [画像・差分]

- 確認用の会話に道具の行が無く、権限は「未取得」のまま。ユーザーの画面で本文を削っていた2つ（道具の箱、確認の帯）は、今回も画像と数値に出ていない。
