# 統合作業環境 第一段階の実装記録

## 対象

2026-11-14、origin/main `248f88a7640440721a7eb02a5a263c93cd2bb5d8` を基点とする `codex/unified-workspace-design-20261114`、0.29.79（初回実装0.29.78、Fable評価対応0.29.79）。PR #93。

Claude DesktopのFable 5.2（UIのモデル欄と`claude-fable-5-2`を確認）へ依頼し、架空データの実操作から設計・仕様・試作を作成してもらった。会話名は「Canban統合作業環境のプロダクト設計」。Codexが実装と独立コードレビューを担当した。

このPRはU1（質問待ちの内容・タスク配下のセッション）とU2（元アプリへ続ける操作）を実装する。U3（まとめる操作と取り消し）、U4（アーカイブ・期間外検索）、U5（観測値だけのガント）は設計済みの後続課題。既定の表示はボードのまま。

## 実装

- Claude / Codex / Antigravityの実際の未回答質問から本文と選択肢を取得。本文120字、選択肢最大6件・各40字。計画承認に質問文を作らない。回答・新しいターンで消去。名前空間付き・非同期質問と形の異なる引数も扱う。
- 時間軸のタスクの下にセッションを入れ子で表示。質問・活動・状態未取得を区別し、独立行と重複させない。j/kの順序、ライブ更新中の選択・フォーカス・スクロールを保持。
- 共通入力欄の上に読み取り専用の質問を表示。Canbanから承認・回答しない。
- セッションのスレッド見出しに元アプリへの主操作を1つ表示。経路ごとのcapabilityと既存の本人・接続・結果不明ガードを維持。詳細パネルには設定を残す。oと⌘Kも同じガードを通す。
- 時間軸のドッキングは選択したカード1枚。拡大したタスクは従来の関連セッション横並びに戻し、閉じると選択カードへ戻る。既存のカードDOM・下書きを再利用。

## 既存前提の修正と移植元

基点の検証で、ガントの直接色指定、iの3方向切替と既存の2方向契約の不一致、テスト終了時のENOTEMPTYを確認した。

- ローカルmainの`c6d1ed7`から`ui/gantt.css`の既存色トークン化と`ui/lifetime.js`のi切替修復だけを移植。
- PR #83の`1f01104`から`tests/helpers.mjs`・`tests/tools-list.test.mjs`・`tests/stop-child.test.mjs`の終了待機だけを移植。
- 他の未push変更やカテゴリ自動合流、テーマ刷新は含めない。登録済みChrome拡張の更新も行わない。

## 検証と証拠

隔離した`makeFixtures()`のデータとChrome、1280×800。実会話への送信・承認は行っていない。スクリーンショットは[変更前](evidence/)と[変更後](evidence/after/)を参照。変更前はClaudeの取得仕様により800×500へ縮小された画像で、操作viewportは1280×800。変更後は1280×800。

時間軸で質問のある子を選ぶ操作は1クリック。変更前は開いても質問が表示されず、変更後は一覧の先頭と入力欄前で本文が読める。見出しの主操作は1つ。変更前後を同条件で対にした速度測定はないため、高速化率や他アプリを超えたとは評価しない。現在の開いて質問が使えるまでの観測値は[measurements.json](evidence/after/measurements.json)に保存する。長会話の更新時間・実機の元アプリ再開時間は未測定。

最終検証の件数とClaudeの体験評価はPR本文と`implementation-review.md`に記録する。

## 仕様とコードの差・未確認

- 設計の一部は`task.links`をID参照として記述していたが、現コードは要約オブジェクト配列。公開形を変えずsignals/activityを追加し、UIはその配列を使う。
- 一覧の質問は先頭120字・選択肢は40字までで、原文全体の代替ではない。元アプリの会話で全文を確認する。
- ガントは基点で追加済みだが既存部品文書の表示契約に未統合で、固定進捗や仮の日程が残る。今回は色・iの契約だけを直し、データの正確性はU5で対処する。
- 利用面バッジは現行の観測規則を維持。Codex Desktopが実際に書く値の網羅確認はなく、推測でCLIをAppへ変えない。
- Claudeの比較・評価と架空データのChrome試験は、登録済みChrome拡張や元アプリで同じ会話へ再開できた証拠とは区別する。今回の成果を登録拡張・ストア版へ反映済みとは扱わない。
