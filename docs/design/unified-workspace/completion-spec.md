# 統合作業環境の完成範囲と会話領域

2026-11-14。基点 origin/main f87e3db、codex/unified-workspace-complete-20261114。ユーザーの今回の「全体構想を完成」と「常設領域を減らして会話・カードのやりとりを大きくする」を、前回U1/U2の後続へ適用する。

## 完成の条件

| 要求 | 実装・確認するもの |
|---|---|
| ハーネスをまたいで仕事を把握 | 元アプリのプロジェクト・環境・利用面を保持したまま、共通のタスクカードへ明示的にまとめる。候補はフォルダ・ブランチ・マシンの根拠を示す |
| まとめる／分ける | x・⌘K・既存所属入口で同じpicker。現在の所属は情報として示し、解除は末尾の独立操作。作成・移動・解除を取り消せ、同時編集を上書きしない |
| アーカイブを含む全体を探す | ⌘Kの明示検索は全期間・アーカイブ・dot・サブエージェントを含む。結果を開いてもボードの条件は変えない。索引・接続・取得失敗を0件にしない |
| 共通の時間軸 | ボード・時間軸・ガントは同じカードを使う。ガントは作成・最終更新・既知の実行/入力待ち・明示期限だけ。開始欠測は点、観測できない継続を補わない |
| カード同士の自由な関連・参照 | 参考（無向）、依存（先→後）、派生（親→子）を明示的に結ぶ。自動観測したreceipt・エージェント親子と混ぜない。自己関連・同型循環を拒否し、相手が未取得でも関係を消さない |
| 会話と入力を広くする | 最小で予約するのはトップバー1本とサイドバー最大1つ。時間帯・カード表示バー・HUD・ナビは小さい入口から開く。同じDOMを再利用し、個別の固定/最小と一括操作を保存する |
| 大きく読んでも作業を失わない | 会話の読む位置・入力下書き・caret・選択カードを、まとめる/取り消し/表示切替/関連参照で保持。新規カードの補助列は閉じ、広いカードで明示的に開いた詳細は横並び、狭いカードでは重ねる |
| 正確な状態と操作 | 未回答質問は既存24時間の観測範囲内で保持し、回答は元アプリ。経路・アカウント・許可境界は自動切替しない。実行/再開成功を「開く操作」から推測しない |

## 小さな補助表示

期間・照らし中・カード表示名・HUDの入力待ち件数をトップバー内の小片で示す。クリックして既存部品をポップオーバーへ一時移動し、閉じると最小に戻る。中のpでその部品だけ固定する。固定された部品の「最小」または⌘Kで戻す。

Alt+Shift+Uは全補助表示の固定／最小。一括の次に行った個別操作は次の一括まで保持。キー案内は独立した既存の開閉・移動を維持し、一括で上書きしない。初期値は右下の最小。オムニの場所入口はキー案内と重ねない。レールは既存サイドバーの内部へ置く。

## 前回設計からの変更

- U3の「現在の仕事を先頭に置き、選ぶと解除」は採用しない。x→Enterが解除にならないよう現在の所属を非選択情報へ移した。
- 0.29.79では既存検証に合わせてiをボード／時間軸の2方向へ戻した。今回ガントを完成させるため3表示を循環し、案内は次に行く表示名を出す。⌘Kには各表示への直接操作を残す。
- 関連の保存・表示は当初第二段階だったが、「全体構想を完成」に必要なため今回含める。予定の自動作成や自動実行には拡大しない。
- 常設の時間帯・ガイド・HUDを減らす今回のユーザー指示を旧部品文書より優先する。文書も同じ契約へ更新する。

## 変更しない判断と検証境界

既定の表示はボード。同名カテゴリの自動合流、ガントの改名、ホワイトボード、実行を自動委譲するオーケストレーターは追加しない。Q1〜Q3は既存の「使ってから判断」を維持し、同名の元プロジェクトを勝手に統合しない。

元アプリに接続できない・APIで操作できない項目は未取得／非対応と示す。架空データでのUI/API試験、登録済みChrome、実会話での再開、production/ストアは区別する。今回のUI確認に実会話送信・承認は使わない。sourceとビルド、PR/CI/mainのSHAを読み戻す。
