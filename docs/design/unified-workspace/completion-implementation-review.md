# 完成版の実装後評価

2026-11-14、Claude Desktop の Fable 5.2（`claude-fable-5-2`）。対象は隔離プレビュー `http://localhost:4635/direct`（0.29.80、架空データのみ）と [completion-spec.md](completion-spec.md)。旧 4633 と設計 prototype は使っていない。

Claude Desktop の内蔵ブラウザで 1280×800、ライトとダーク。配置は Trello を中心に、HUD とオムニを最小の状態だけ見た。設計レビューの原文 [completion-design-review.md](completion-design-review.md) は変更していない。

外部アプリの起動、実会話への送信、承認は行っていない。「Codex で開く」「Claude で答える」は押していない。製品コードの編集、コミット、サーバー停止もしていない。

## 結論

依頼の6経路は、すべて最後まで歩けた。設計レビュー #1〜#6 は対応を確認した。必須の動作で壊れているものはない。

残る問題は3つ。1つは今回の目的そのものに関わる。

| # | 内容 | 重さ |
|---|---|---|
| C1 | 会話が読める高さは 800px 中 241px。固定領域を減らしても増えていない | 目的に対して未達 |
| C2 | ⌘K で「調査」→ `Enter` が、カードを開かずラベルの絞り込みになる | 不具合 |
| C3 | ⌘K で開いたボード外のカードから `Esc` で戻ると、元のカードに戻らない | 不具合 |

## 確認した経路

### ① 最小の状態表示 → ポップアップ → 個別固定 → 再読み込み

- 最小では、トップバーに「期間 30日」が出る。カードを開くと「プレビュー」、時間軸では「入力待ち 1」も出る。
- 「期間 30日」を押すと、時間の帯がポップオーバーで開く。中身は既存の帯そのもの（同じ DOM）だった。フォーカスは「固定する p」に入る。
- `p` で帯だけが固定され、ボタンの表示は「個別」になる。再読み込み後も固定のまま（保存値 `ribbon: pinned`、ほかは `minimal`）。
- `Alt+Shift+U` で全部固定、もう一度で全部最小。キー案内の保存値はこの操作で変わらなかった。
- 照らすと小片は「期間 30日 · 照らし中 動いている」になり、`Esc` で解除すると「期間 30日」に戻る。

結果: 合格。設計レビュー #1・#2 は解消。

### ② 仕事にまとめる・明示解除・取り消し

- 「決済フォームの検証」に入っている「README 修正」で `x`。既定の選択は「新しいタスクカードにまとめる」。現在の所属は下端に情報として出て、選べない。
- `Enter` で新しいタスクカードへ移動した。トースト「取り消す」が出る。トーストが消えたあとも ⌘K の「仕事にまとめた操作を取り消す」で戻せた。作ったタスクカードも消えた。
- `x` → `↓` →「この仕事から外す」→ `Enter` で解除。トーストの「取り消す」で元の所属に戻った。
- どの操作のあとも、選択中のカード、会話の読む位置（218・219 番のメッセージ）は変わらなかった。

結果: 合格。設計レビュー #3 は解消。

### ③ ⌘K でアーカイブを開いて戻る

- ⌘K に「調査」と入れると、「ボードの外」に「調査（Codex · CLI · アーカイブ済み）」が出る。件数「ボードの外: 1件」も出る。
- 開くと右にドッキングした。一覧の3行、期間 30日、「dotを除く」は変わらなかった。
- ここで C2 と C3 を見つけた（下記）。

結果: 条件を変えずに開ける点は合格。既定の選択と戻り先に不具合。

### ④ `i` の3表示とガント

- `i` はボード → 時間軸 → ガント → ボードと一周した。
- キー案内は時間軸で「i ガント」、ガントで「i ボード」と出て、動作と合う。ボードでは「i ボード」と出た（C4）。
- ガントは固定の進捗率も未来の帯もない。凡例は「帯は観測した活動の期間です。予定ではありません」。
- 「ログイン修正」（最終更新 9/21）は帯がなく「時刻は未取得・期間外」と出る。入力待ちの「README 修正」は期間の左端から現在まで帯が伸び、タスクは子の範囲を枠で示す。
- カードを選ぶとガントは左の細い列に縮む。帯は読めるが、日付の目盛りは2つになる。

結果: 合格。設計レビュー #4 は、ボードでの文言を除いて解消。

### ⑤ 関連するカード

- `Alt+Shift+R` で詳細パネルの「関連するカード」が開き、「カードを関連付ける」にフォーカスが入る。
- 種類を選び、次に相手を選ぶ2段。相手の一覧は全期間・アーカイブを含む。
- 参考（調査）、依存（README → ログイン修正）、派生（決済フォームの検証 → README）を結べた。
- 逆向きの依存（ログイン修正 → README）は「同じ種類の関連が循環するため追加できません」で拒否され、件数は変わらなかった。
- 「調査」を押すと移動し、相手側にも「参考（双方向）README 修正」が出た。「前のカードへ戻る」で README に戻れた。
- 戻ったあと、下書き、キャレット位置（7文字目）、読む位置（scrollTop 6000）、一覧の選択が元のままだった。
- 再読み込み後も3件の関連は残っていた。

結果: 合格。自己辺の拒否は、相手の一覧に自分が出ないことまでしか見ていない。

### ⑥ 220 メッセージの会話

- 下書き「下書きテスト abc」を入れ、キャレットを3文字戻し、会話を途中まで巻き戻した状態で確認した。
- 関連カードへの移動と復帰、`Enter` で拡大、`Esc` でドッキング、詳細パネルの開閉、まとめる・取り消しのどれでも、下書き・キャレット・読む位置は保たれた。
- 新しく開いたカードは「思考」と「詳細」が閉じている。
- 拡大したカード（幅 1248px）で `d` を押すと、詳細は 280px の横並びになり会話は 968px。ドッキング（幅 724px）では重なる。設計レビュー #5 は解消。
- ページを再読み込みすると下書きは消えた。仕様の保持対象に再読み込みは入っていないので、観測として記録する。

結果: 保持は合格。会話の面積は C1。

### ダークと他の配置

- ダークで、最小の小片、時間の帯のポップオーバー、関連するカード、照らし中の表示を見た。読めない文字や崩れはなかった。
- HUD 配置の最小では、全幅の HUD 行は出ない。トップバーの「入力待ち 1」を押すと実行状況がポップオーバーで開く。
- オムニ配置の最小では、サイドバーなし、カード幅 984px。右下に「場所」ボタンが浮く。
- どちらも、場所を予約しているのはトップバーと（あれば）サイドバーだけだった。設計レビュー #6 は解消。

## 不具合と未達

### C1 会話の高さが増えていない（目的に対して未達）

時間軸で「README 修正」を開いたときの縦の内訳（1280×800、Trello、最小、詳細は閉じた状態）:

| 部分 | 高さ |
|---|---|
| トップバー | 52px |
| カード見出し（パンくず・続けるボタン・理由の3行） | 108px |
| タイトル | 33px |
| 状態の行 | 28px |
| **会話** | **241px** |
| 質問と入力欄 | 287px |

会話はカードの3分の1で、メッセージは2件しか見えない。拡大しても会話は 265px で、ほとんど変わらない。横はドッキング 724px、拡大 1248px、オムニ 984px。

時間の帯や HUD を畳んだ効果は、この画面では縦に出ていない。もともと時間軸ではそれらが場所を取っていなかったからで、取っているのはカード自身の見出しと入力欄である。ユーザーの「やりとりを大きく」に応えるには、ここを削る必要がある。

変更前の同条件の数値は手元にないので、「前より増えた／減った」とは言わない。Codex の前後計測と突き合わせてほしい。

修正案（効果の大きい順）:

1. 見出しを1行にする。続けるボタンの無効理由は、ボタンの下の行ではなくボタンの中か `title` に入れる。パンくずとツールを同じ行に収める。これで約 60px。
2. 質問の表示を畳めるようにする。質問文は一覧の行と会話の末尾にも出ているので、入力欄の上は1行の要約にして、押すと選択肢が開く形でよい。これで約 70px。
3. 入力欄の下の2行（「セッションが入力待ちです…」とキーの凡例）を1行にまとめる。これで約 25px。

3つで会話は約 400px になり、いまの 1.6 倍になる。

### C2 ⌘K の既定の選択がラベルになる

「調査」と入れると、「ボードの外」のカードが上、ラベル「調査」が下に並ぶ。選択はラベルに付いている。そのまま `Enter` を押すと、アーカイブのカードは開かず、ラベルの絞り込みがかかる。「結果を開いてもボードの条件は変えない」という仕様の逆の結果になる。

ボードの外の結果はあとから届くので、先にあった項目に選択が残るのが原因と見ている。結果が届いたら、利用者がまだ矢印キーを押していない場合は選択を先頭に置き直す。

証拠: [03-palette-archive-default-selection.jpg](evidence/completion/03-palette-archive-default-selection.jpg)

### C3 ボード外のカードから戻ると元のカードに戻らない

「README 修正」を開いた状態から ⌘K で「調査」を開き、`Esc` を押した。フォーカスは一覧の先頭「決済フォームの検証」に移り、右のカードは「調査」のまま残った。一覧に選択中の行はない。直前に読んでいた「README 修正」には戻らない。

関連カードには「前のカードへ戻る」があるので、同じ仕組みを ⌘K から開いた場合にも使うのがよい。`Esc` で直前のカードと行の選択に戻す。

### C4 ボードでのキー案内

ボードでキー案内は「i ボード」と出る。次の表示は時間軸。時間軸とガントでは正しい。

### C5 開いたカードにアーカイブ済みの表示がない

⌘K から開いた「調査」のカードには、アーカイブ済みであることも、ボードの外であることも出ない。一覧に選択がないので、なぜ行がないのかが分からない。状態の行に「アーカイブ済み」を出す。

### C6 照らし中の小片が一度だけ古いままだった

ダークで、帯のポップオーバーから「動いている」を照らして `Esc` で閉じたところ、行は薄くなっているのに小片は「期間 30日」のままだった。続けて `Esc` を押しても照らしは消えなかった。同じ操作をもう一度行うと正しく「照らし中 動いている」と出て、`Esc` で解除できた。再現は1回だけで、条件は特定できていない。

## 小さな改善案

- **`x` → `Enter` の既定**: すでに仕事に入っているセッションでは、既定が「新しいタスクカードにまとめる」なので、`Enter` で仕事から出てしまう。取り消せるので害は小さいが、所属があるときは既定を置かないほうが安全。
- **固定した直後の照らし**: `p` で帯を固定した直後、「動いているを照らしています」が出た。再読み込みで消えた。固定の操作で照らしが始まらないようにする。
- **ガントの凡例**: 「README 修正」の帯は作成から現在までで、その間ずっと動いていたわけではない。凡例は「最初の記録から最後の記録まで」のほうが正確。
- **「時刻は未取得・期間外」**: 2つの理由が1つの文言になっている。「ログイン修正」は期間外なので「期間外（9/21）」と出し分ける。
- **依存の文言**: 「このカードが先に必要 → 相手」は読みにくい。「先: このカード → 後: ログイン修正」のように両方の名前を出す。
- **ドッキング中の詳細パネル**: 重なると入力欄の右端と送信ボタンが隠れる。開いている間は入力欄をパネルの左で折り返す。
- **オムニの「場所」ボタン**: 送信ボタンのすぐ下に浮く。重なってはいないが、押し間違えやすい位置。
- **開いたキー案内**: 右下で開くと、カードの送信ボタンに重なる。
- **HUD 配置のトップバー**: 時間軸・ガントの切り替えボタンが見えず、いまどの表示かをトップバーで確認できない。今回の変更によるものかは未確認。
