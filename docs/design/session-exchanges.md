# セッション間のやり取り

承認された2026-10-14の画像プレビューを実装する。セッションカードの吹き出しからレイヤー4のポップオーバーを開き、同じ取得済み履歴を「時系列」「相手別」で切り替える。別セッションは対等な関係で、タスクカードのlinks・サブエージェントの起動関係と混ぜない。

- カードの属性行・休眠カードの1行・時間軸に送信先数／受信元数を表示する。サブエージェントの既存表示を維持する。
- 受信側の完全なcodex_delegation封筒（source_thread_idとinput）を根拠にする。UserMessage、旧user_message、codex_appのcreate_thread/send_message_to_threadが注入するFunctionCallOutput.outputを扱う。fco IDで二重記録をまとめる。旧／新のメッセージ記録は同一の送信元・受信先・時刻・本文で重複を取り除き、異なるmessage IDは残す。明示されたCodexのcollab interaction/spawn完了イベントも扱う。本文の類似、ブランチ、送信要求だけから関係を作らない。
- 現在のセッションから見た送受信方向を表示し、相手名・時刻・本文を持つ。同じ相手への繰り返しを残す。既知の起動関係だけをサブエージェント／親セッション／同じ実行のエージェントとして示す。
- 時系列は新しい順。相手別は最近のやり取り順で並べ、各相手内も新しい順。相手別はdetailsで折りたためる。見出しと2択のボタンは固定し、履歴だけをスクロールする。
- 取得は読み取り専用。カードの既読化・移動・送信・自動化を呼ばない。取得できない相手はIDと「未取得」を表示し、取得範囲が一部の場合は明示する。
- ローカルログは変更時だけ追加分を読み、初回は256KiBの末尾を読む。ファイルの削除・切詰め・置換を検知する。相手が非表示でも履歴には残す。リモート／クラウドのログ取得は今回のローカル経路で代用しない。
- 操作は吹き出し1クリック、選択カードのShift+M、⌘K「セッション間のやり取り」。Escは最上位のポップオーバーだけを閉じる。表示切替は押下状態を伝えるbutton groupとし、Tabで操作できる。
- 未記録のやり取りや返信・依頼の完了を推測しない。履歴が取れていないサブエージェントも既存の起動情報と状態で確認できる。

検証: 封筒の偽陽性・重複・同一相手への反復・ホスト分離・起動関係・キャッシュ更新／削除、実ブラウザで両ビュー・キーボード・ライト／ダーク・ボード／時間軸を確認する。
