# タスクごとのカードダッシュボード

## 採用する仕様

タスクカードは仕事の情報・通常セッションへの明示的なリンク・独立したダッシュボード設定を保持する。ダッシュボードは既存の pane と会話・送信・ライブ更新を使う。エージェントのセッション／サブエージェント階層は変更しない。

- ホームからタスクを開くと、その親ペインと全関連する通常セッションを1つの作業画面に開く。既存リンクが読み取れない場合は消さず、再読込可能な表示を残す。
- A（左右分割）・B（上下分割）では親と選択中の会話を表示し、他の関連会話は切替一覧から開く。C（並列）と自由配置では複数の会話を表示する。
- 初回はA。タスクごとの配置、選択中の会話、順序、サイズ、付箋状態、自由配置の位置、ペイン内部の部品配置・高さ・比率を保存する。
- タスクを閉じても構成とリンクは保持する。子ペインを閉じてもリンクは保持し、次にタスクを開いたときは関連セッションとして復元する。紐付け解除は「タスクから外す」でのみ行う。
- 別タスクへ移る際は表示ペインを退避し、未保存の入力・依頼文は同じページ内で保持する。タスク外の一般ダッシュボードも退避／復元する。入力途中の文章は共有設定に保存しない。
- タスクの説明・メモから、新規開始／選択した既存会話への依頼文を編集可能な形で作成できる。送信には既存の実行状態・権限確認をそのまま使う。
- 保存するのは表示構成であり、会話や実行状態のコピーではない。開くと最新のセッション情報を読む。
- タスクごとの更新はリビジョンで競合検知し、他画面からの変更を自動で上書きしない。
- 関連セッション数と、同時に会話をライブ表示する数を分ける。8件を超えてもリンクや保存配置を切り捨てず、選択／ページ切替で全件にアクセスできる。

## 実装順

1. 独立した作業ツリー `codex/task-dashboard-state` で、保存データの正規化とStoreの読み書き、MCPの読取・保存操作を実装する。
2. `codex/card-dashboard-ux` の変更が `origin/main` に入ったことを確認して更新する。その親ペイン化・部品リサイズ・カテゴリ分類・一括表示を維持する。
3. 共通のタスクダッシュボード制御を専用のUIファイルに実装し、既存の `openCard` / `savePanes` / 配置処理へ限定的なフックを追加する。
4. ABCと自由配置、親カードの識別、セッション切替、構成の保存状態、再読み込みを実装する。
5. 説明・メモからの依頼作成と、明示的な紐付け変更を接続する。
6. Store／MCP／表示・復元の回帰テスト、Chromeビルド、fixtureのブラウザーで受け入れ確認する。

## 検証する契約

- 複数タスクの設定を独立して読み書きでき、リンクや本文を変えない。
- パネルを閉じても再度タスクから復元できる。
- 同時保存の競合では旧リビジョンの書き込みを拒否し、保存済みの設定を返す。
- リンクの追加・解除、新規開始、読み取れない会話を含む復元を扱える。
- ABC／自由配置を切り替えても入力途中の文字を保持する。
- 9件以上の関連セッション、一般ダッシュボードとの切替、リロード復元を確認する。
- 先行の一括表示、折り畳み、最後のパネルからホーム、部品の移動・高さ・比率・カテゴリ分類を回帰確認する。

## 保存する情報

`task.dashboard = { revision, state }`。`state` は `preset`（A/B/C/free）、`activeSessionId`、`paneGlobal`、`paneLayout`、`panes`。ペインは親タスクまたはリンク済みセッションのIDと表示設定のみ。将来の追加に備えて形式はversion付きで、未知のキーと本文・依頼文・セッション状態は保存しない。
