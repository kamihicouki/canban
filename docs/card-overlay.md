# カードオーバーレイ UI / UX

カードを押すと、ページを切り替えずに、ボードの上へ背景を少し暗くしてカードを浮かせる（Trello の「カードの裏」）。0.18.3 までの複数カード同時表示・自由配置・ダッシュボードボタンは廃止し、予測しやすい標準の動きに戻した。

## 操作と状態

- セッションカードを押すと、そのカード1枚だけが開く。
- タスクカードを押すと、タスクのカードを左端に、紐付いたセッション（サブエージェントを除く）を右へ横並びで開く。横に並べるのは最大8件。残りは、タスクの「紐付いたセッション」から個別に開く。
- 並んだセッションは、紐付けの増減に自動で追従する。すでに並んでいるカードは位置を保ち、新しい紐付けは末尾に付く。「紐付いたセッション」の会話名は、並んだカードへスクロールする。
- カードを開いたまま、`j` / `k` でボードの次 / 前のカードへ移る（表示順。端では止まり、リストの続きは自動で読み込む）。閉じたあとのフォーカスは、最後に見ていたカードに戻る。
- そのほか、`[` `]` で横に並んだ隣のカード、`1` `2` `3` で会話の表示、`i` で指示の入力欄、`o` `l` `g` `m` `h` で再開・ラベル・カテゴリ・リスト移動・隠す、`?` でキー一覧（0.22.0）。使えるキーは、バーとボタンの隣に小さなキーの形（`.keycap`）で示す。分析・Agent Usage のシートでは `?` と `Esc` だけ。
- `Esc`、背景の押下、右上の「閉じる」で閉じる。閉じるのは一番上の1枚（オーバーレイ）だけで、ボードの位置・選択・入力途中の文章は失わない。
- アプリバーは隠さない。オーバーレイはアプリバーの下から始め、ボード（サイドバーを含む）は閉じるまで操作できない。
- 閉じたカードは DOM を保持し（最大16枚）、開き直すと入力途中の文章が戻る。リロード後は、開いていた1枚（タスクなら並んだカードごと）を開き直す。開いているカードは画面間で共有しない。
- 管理パネル（レイヤー1）はオーバーレイの下に残る。⌘K などから管理のページを開くと、オーバーレイは閉じる。
- 分析と Agent Usage も、同じオーバーレイにシートとして開く（0.20.0）。
- 狭い画面でもカード内は2列を維持する。最小幅560pxより狭い表示領域ではカードボード内を横にスクロールする。

## カードの中のレイアウト

- 部品の並び替え（列をまたぐ移動）、高さ、2列の境界、開閉は、これまでどおり変更できる。
- カード幅は、カードの右端のドラッグ（または `←` `→`）で変える（560〜1600px）。高さは下端（`↑` `↓`）、縦横は右下で変更する（高さ320〜1600px）。`Home`は既定値へ戻す。表示高さは画面内に収まる値までとする。
- 配置・列幅・高さ・開閉・カード幅は、カードの種類（セッション・タスク）ごとに持ち、同じ種類のカードで共有する。共有 UI 状態の `cardLayouts`・`cardWidths`・`cardHeights` に保存し、画面間で同期する。セッションとタスクは独立している。初期値はセッション1000px、タスク760px、高さは両方860px。
- 表示モード（テキスト・プレビュー・要点）は全カード共通（`paneGlobal.mode`）。
- 「レイアウトを初期化」は、いま開いている種類の配置・列幅・部品の高さ・カードサイズだけを初期値に戻す。

## 整理したもの

- 複数カードの選択と一括表示（ホームのチェックボックス、選択バー）、固定・自由の空間、並べ方、サイズ（S・M・L）、付箋、ダッシュボードボタン、階層メーター、`カード` ページ（サイドバーの「カードダッシュボード」）を削除した。
- タスクごとの画面設定（A 左右・B 上下・C 並列・自由、選択中の会話）の UI を削除した。サーバー側の `canban_get_task_dashboard` / `canban_save_task_dashboard` と保存データは、互換のため残してある（画面は使わない）。
- 古い共有 UI 状態の `panes`、`dashOpen`、`paneLayout`、`activeTask` などは読み捨てる。

## カテゴリ

独立した Canban プロジェクト一覧・絞り込み・スイムレーン・コマンド・分析の呼称をカテゴリへ統合した。旧保存ビューのプロジェクト絞り込みは同名カテゴリへ移行する。従来の API フィールドは互換性のため残す。

明示的なカードのカテゴリ指定を最優先する。`__none` は特殊カテゴリ「カテゴリ無し」への指定。

- Codex: `codexProject` を使用する。project がないセッションは作業フォルダに関係なく「カテゴリ無し」。
- Claude: group 情報がある場合はその名前を使用し、ない場合は作業フォルダ名／パスへフォールバックする。
- ソースに由来するカテゴリの関連は名前変更後も維持する。削除した自動カテゴリは直後の読み込みで再作成しない。
- 既存のカテゴリとパス設定は保持する。パスによる自動分類はタスクに使用する。

Claude の現在のローカル `local_*.json` にはカスタム sidebar group の情報が含まれていない。現行アプリの group は renderer から session manager に通知されるため、このファイル読み取りだけでは実際の所属を取得できない。group metadata (`group` または `groupName` / `groupId`) の分類は fixture で確認済み。インストール済み Claude の実際の group を取得する経路は未対応で、現状はフォルダへフォールバックする。

## カード内の既定配置（0.23.0）

左は会話・説明と入力、右はパンくず・見出し・状態と属性。固定の全幅ヘッダーは置かず、会話がカード上端から始まる。パンくず・見出し・状態も、ほかの部品と同じつまみで列間移動・並べ替えできる。閉じる操作は右上に固定する。

会話はHuman右・Agent左の吹き出し。既定の会話高さは入力欄を除く空間へ広がり、ユーザーが部品の高さを指定した場合はその指定を優先する。会話のスクロールと読み取り位置、添付、キュー、制限なし権限の確認は既存の処理を維持する。

つまみは6点を小さく薄く表示し、ホバー・フォーカスで強調する。つまみの矢印キーで移動・並べ替え、境界の矢印キーでサイズを変更する。⌘Kにも部品の移動・列幅・カードサイズ・リセットの入口を載せる（レイヤー2）。旧版の未変更の既定配置だけを新配置へ移行し、カスタム配置と高さは保持する。

カード外の余白・ショートカットマップ・バーとの間隔はカードボード側の受け持ち。本変更ではその配置を定めない。
