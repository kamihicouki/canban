# 会話を読む領域の改善

ユーザーの添付画面とFable 5.2の評価に基づき、共有カードの本文を優先する。既存の部品と操作を維持する。

- 案: 自動でサイドバーを閉じる / 新しい表示を足す / 共有スレッドの余白・折畳みツール・一覧幅を直接整える。今回は最後を採用する（Codex判断）。既存bで2列にでき、保存されたサイドバーの選択を上書きしない。
- 既存thread.cssのツール履歴を28px程度の行にし、発言との間隔を短くする。本文・入力・タスク説明にNoto Sans JPを同梱し、16pxと等幅コードを維持。本文幅は従来の60rem・全面1120pxを維持する。
- inbox/ganttの一覧は会話用の領域を優先して272〜304pxにする。期間・状態・帯は残し、内容をCSSで隠して別部品を作らない。
- 送信前の権限確認は今回の対象外。非表示や条件変更は行わない。既存レイヤーとキーのみ。
- boardHtmlでローカルWOFF2を自己完結のCSSへ組み込み、Chrome/MCP/ローカルで外部通信なし。OFLと固定ソースSHAを残す。
- 配布字体の試験を先に失敗確認→実装→npm test、Chrome smokeと1280×800 light/dark、board/timeline/ganttとtask/session、scroll/draft/keyboard確認→日本語commit/PR/CI/main→登録拡張更新。
