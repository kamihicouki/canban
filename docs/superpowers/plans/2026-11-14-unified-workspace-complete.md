# 統合作業環境の完成と会話面積の拡大 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 既存Fable設計のU3/U4/U5を実装し、常設領域をトップバー1本・サイドバー1つを中心に縮小し、仕事・会話・関連を広く使えるようにする。
**Architecture:** 同一ボードと既存カードを保ち、まとめる操作・全期間検索・観測した時間の可視化を追加する。補助表示は既存部品を最小／固定へ切り替え、本文の領域を優先する。
**Tech Stack:** 現行のvanilla JS/CSS、MCP server、Node test、Chrome CDP。
**Spec:** docs/design/unified-workspace/implementation-spec.md と今回のユーザー指示。

## 制約

最新origin/main基点の専用ブランチ。他checkoutの未push変更を混ぜない。1ページ・既存トークン・原文・状態の精度・下書き・スクロール・実行経路のガードを維持。CLI/アプリで取得不能な情報は未取得として示す。実会話送信・承認で試験しない。ユーザーの「固定領域を減らす」は旧UI文書の常設時間帯・補助列より優先する。

## 実装単位

- [x] U3: 根拠付きの仕事候補、新規タスクへのまとめ、移動・解除、競合を壊さない取り消し。x/⌘K/既存所属入口を同じpickerへ。
- [x] U4: ⌘Kからアーカイブ・期間外・絞り込み外を検索、取得失敗と古い応答を区別、AI App/利用面/理由を表示。
- [x] U5: 固定進捗・架空期間を除去、観測開始/更新/現在/期限、欠測の点、タスクの子範囲、共通期間・キー・保存復元。
- [x] 会話面積: 時間の帯を必要時に開く。キー案内・オムニバー/HUDは最小／固定を選び、会話の領域を予約しない。詳細属性・思考補助列は初期には閉じ、操作時に開く。本文・入力欄・関連カードを優先。
- [x] カード同士の関連: 参考・依存・派生を明示的に保存/解除/参照し、観測したreceiptやエージェント親子から区別する。循環と自己関連を拒否し、相手が未取得でも既存関係を壊さない。既存詳細とpicker/カード部品を使い、新しい固定領域は作らない。
- [x] Fable: 実際のDesktopの既存会話へ追加意図と実装を共有し、架空データで体験評価。Codexが実装・独立コードレビュー。
- [x] 統合: コンポーネント文書・バージョン3箇所・変更履歴、必要なテスト、npm test、Chrome smoke、5配置、1280×800ライト/ダーク、計測前後、ビルドとソースの一致。
- [ ] 日本語コミット・PR・セルフレビュー・CI・条件付きmainマージの読み戻し。登録済み拡張への反映は別ゲートとして記録。
