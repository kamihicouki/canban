# 画面のコンポーネントと呼称

Canban の画面を作る部品の名前と、それぞれが受け持つことを決める。UI の文言・コード・PR・会話では、ここにある呼称を使う。新しい部品を足すときは、まずこの表に入るかを確かめる。入らないときは、この文書に足してから実装する。

## 原則

- **入口は1か所。** 同じ場所へ行く入口を、1つのレイアウトの中に2つ置かない。ナビゲーション（サイドバー・レール・ドック・タブ）が、そのレイアウトでの唯一の索引になる。
- **開いたものは、同じ入口で閉じる。** 開いている項目をもう一度押すと閉じる。加えて `Esc` で閉じる。
- **バーは1本。** アプリ全体の操作とボードの操作を、1本のアプリバーにまとめる。2段目のツールバーは作らない。
- **絞り込みは見える場所に、見え方の好みは奥に。** カードを絞り込む操作はサイドバーに常に出し、有効な条件はアプリバーにチップで示す。カードの高さ・レイアウト・色は「レイアウトとテーマ」にまとめ、1段深い場所に置く。
- **何も選ばなければ、すべて見える。** 絞り込みは押した値だけに絞る。レーンにした軸は絞り込みに出さない。
- **ボードは見えたまま。** 管理パネルはボードを押し出して隣に開き、カード・分析・Agent Usage はボードの上の半透明のオーバーレイに開く。ページ遷移はしない。

## レイヤー

ボードをレイヤー1とする。収まる中で一番低いレイヤーを使う。`Esc` と背景の押下で閉じるのは、一番上の1枚だけ。

| レイヤー | 名前 | 受け持つもの | 実装 |
|---|---|---|---|
| 1 | ボード面 | アプリバー、ナビゲーション、管理パネル、ボード | `board.html` / `workspace.js` / `layouts.*` |
| 2 | オーバーレイ | カード（セッション1枚、またはタスクと紐付いたセッションの横並び）、分析シート、Agent Usage シート | `card-overlay.*`（`#paneLayer`） |
| 3 | ダイアログ | 確認、タスクの追加 | `<dialog>`、`task-quick-add.*` |
| 4 | ポップオーバー | 表示、ピッカー、リストメニュー、アカウント | `popover()` |
| 5 | パレット | ⌘K コマンドパレット、ショートカット一覧 | `commandPalette()` |

## コンポーネント

| 呼称 | コード上の名前 | レイヤー | 受け持つこと | 置くもの |
|---|---|---|---|---|
| アプリバー | `.topbar`（`.appbar`） | 1 | アプリ全体と、いま見ているボードの操作 | ナビゲーションの開閉、ロゴ、ボード名、検索・⌘K、作成、絞り込みのチップ、実行状況、既読、アカウント、再読み込み |
| ボード名 | `#logo`（`.board-name`） | 1 | 一致する保存ビューの名前を示し、押すとカテゴリ・プロジェクト・フォルダで絞り込む | 「すべてのセッション ▾」など |
| 絞り込みのチップ | `#filterChips`（`renderFilterChips()`） | 1 | 有効な絞り込みを一目で示し、✕ で1つずつ外す | 「Codex ✕」「30日以内 ✕」「すべて解除」 |
| レイアウトとテーマ | `lookMenu()` | 4 | カードとリストの見え方（好み） | カードの高さ、レーン内のリストの高さ、レイアウト、色 |
| ナビゲーション | — | 1 | どこを見るかを選ぶ。レイアウトごとに次のどれか1つ | サイドバー・レール・ドック・タブ |
| ワークスペースサイドバー | `#sidebar` | 1 | どこを見るか、何を見るか | 上から ビュー、レーン、絞り込み。下端に 見る（分析・Agent Usage）、管理、レイアウトとテーマ |
| ビュー | `.side-sec-views` | 1 | 保存した絞り込みを1クリックで切り替える | すべてのセッション、保存ビュー、＋ 保存 |
| レーン | `laneSection()` | 1 | ボードを横に分ける軸を選び、各レーンへ移動する | 軸（なし・カテゴリ・AI Apps・マシン・ラベル・⋯）、レーンの一覧（押すと移動、▾ で開閉、⌥ で単独表示） |
| 絞り込み | `filterSection()` | 1 | 表示するカードを絞る。1つ選ぶと絞り、もう一度押すと解除 | AI Apps、期間、状態、カテゴリ（⚙ で管理）、マシン、ラベル、表示する対象 |
| レール | `.layout-rail` | 1 | レールのレイアウトのナビゲーション | ボード、分析、Agent Usage、管理の各項目 |
| ドック | `.layout-dock` | 1 | オムニバーのレイアウトのナビゲーション | ボード、分析、Agent Usage、管理の各項目 |
| タブ | `.layout-tabs` | 1 | ライブ HUD のレイアウトで、ボードとシートを切り替える | ボード、分析、Agent Usage |
| カテゴリの帯 | `.cat-strip` | 1 | オムニバーのレイアウトで、レーンへ移動する（レーンなしのときはカテゴリで絞り込む） | レーンまたはカテゴリのピル |
| 絞り込みボタン | `.omni-filter` | 1→4 | オムニバーのレイアウトで、レーンと絞り込みをポップオーバーで開く | 件数つきの「絞り込み」 |
| ライブ HUD | `.live-hud` | 1 | 実行中・入力待ちのセッションを常に見せる | セッションのタイル |
| 管理パネル | `.mgmt-drawer`（`workspace`） | 1 | 管理の各ページの中身。ナビゲーションの隣に開き、ボードを押し出す。タブは持たない | 自動化、ラベル、カテゴリ、保存ビュー、マシン、設定 |
| ボード | `#board` | 1 | 仕事そのもの | リスト、カード、スイムレーン |
| オーバーレイ | `#paneLayer` | 2 | ボードを少し暗くして、その上に1つだけ浮かべる | カード、シート |
| カード（詳細） | `.pane[data-kind=session/task]` | 2 | セッション・タスクの裏面 | 部品（会話・指示・メモなど） |
| シート | `.pane.sheet[data-kind=view]` | 2 | ボード全体を集計した表示 | 分析、Agent Usage |
| 部品 | `.psec` | 2 | カードの中の1区画。並び・高さ・開閉はカードの種類ごとに共有する | — |
| キーのヒント | `.keycap` / `keycap()` / `keyHint()` | — | その画面で使えるキーを、操作の隣に `Esc` のような小さなキーの形で示す。別の入口にはしない | カードのバー（`j` `k` `[` `]` `?` `Esc`、`1` `2` `3`）、カード内のボタン（`o` `l` `g` `m` `h` `i`）、アプリバー（`/` `⌘K` `c`） |

ボード上の1枚は「カード」と呼ぶ。オーバーレイで開いた裏面も、区別が必要なときは「カードの詳細」と呼ぶ。

## 管理パネルのページ

### カード内の部品

- 主情報の列と属性の列は、タスク・セッションとも常に2列。既定では会話・説明と入力を左、属性を右に置く。
- パンくず・見出し・状態は、それぞれ独立した可動部品。既定は右列の先頭。部品のつまみは控えめな6点で、ホバーとキーボードフォーカスで強調する。
- 部品はつまみのドラッグまたは矢印キーで列間移動・並べ替え、下端の境界で高さを調整する。列の境界で列幅を変える。
- カードのサイズは右端・下端・右下で調整する。幅と高さ、部品の配置は種類ごとに共有 UI 状態へ保存する。閉じる操作は固定し、部品を移動しても届く。
- カード外の余白・ショートカットマップはカードボードの受け持ち。カード内の配置変更では変更しない。


| ページ | `workspace.page` | 中身 |
|---|---|---|
| 自動化 | `rules` | カードの自動移動のルール |
| ラベル | `labels` | ラベルの作成・名前・色 |
| カテゴリ | `directories` | カテゴリの作成・設定 |
| 保存ビュー | `views` | 絞り込みの保存 |
| マシン | `hosts` | リモート接続 |
| 設定 | `settings` | 再開・送信、アカウント、ショートカット |

`home` は管理パネルを閉じた状態で、ボードだけが見える。分析と Agent Usage はページではなく、オーバーレイのシート（`view:analytics` / `view:usage`）として開く。

## レイアウトごとの配置

部品は5種で共通。並べ方だけを `body[data-layout]` で変える。どのレイアウトでも、管理パネルはナビゲーションの隣に開き、カード・シートはオーバーレイに開く。

| レイアウト | ナビゲーション | アプリバー | 管理パネルの位置 | 固有の部品 |
|---|---|---|---|---|
| Trello（既定） | サイドバー（ビュー・レーン・絞り込み、下端に見る・管理・レイアウトとテーマ） | 全幅 | サイドバーの右 | — |
| 定番 | サイドバー（上まで通り、ロゴを持つ） | サイドバーの右 | サイドバーの右 | — |
| レール | レール（すべての場所とレイアウトとテーマ）。隣の列はビュー・レーン・絞り込み | レールとサイドバーの右 | サイドバーの列（開いている間は差し替える） | レール |
| オムニバー | ドック（すべての場所とレイアウトとテーマ） | 全幅。検索、カテゴリの帯、絞り込みボタンを置く | 左端 | ドック、カテゴリの帯、絞り込みボタン |
| ライブ HUD | タブ（ボード・分析・Agent Usage）とサイドバー（ビュー・レーン・絞り込み、下端に管理・レイアウトとテーマ） | 全幅。タブを置く | サイドバーの右 | タブ、ライブ HUD |

## 削除した入口（0.20.0）

| 削除したもの | 代わりの入口 |
|---|---|
| ボードバー（2段目のツールバー） | アプリバーに統合 |
| ボードバーの「メニュー」ボタン、管理ドロワーのタブ | ナビゲーションの「管理」 |
| ボードバーの「ボード / 分析」 | ナビゲーションの「分析」（オーバーレイのシート）、`a` キー |
| 管理ドロワーの「Agent Usage」タブ、利用上限のチップ | ナビゲーションの「Agent Usage」（オーバーレイのシート）、アカウントボタン |
| ボードバーのカテゴリ絞り込み（📁） | サイドバーのカテゴリ、ボード名、`p` キー |
| ボードバーの「揃える / 内容に合わせる」 | 表示メニュー |
| ヘッダーのテーマ切り替え・レイアウトボタン、設定の「表示」タブ、レールのテーマ・レイアウトボタン | 表示メニューの「レイアウトと色」、⌘K |
| ドックの「＋ タスク」 | アプリバーの「作成」、`c` キー |
| ライブ HUD の「管理」タブ | サイドバーの「管理」 |

## 削除・移動した入口（0.21.0）

| 変えたもの | 新しい場所 |
|---|---|
| アプリバーの AI Apps・期間 | サイドバーの「絞り込み」。有効な条件はアプリバーのチップ |
| アプリバーの「表示」メニュー | 見え方は「レイアウトとテーマ」（サイドバーの下端・レール・ドック）。表示する対象（アーカイブ済みなど）は「絞り込み」 |
| 表示メニューのスイムレーン | サイドバーの「レーン」 |
| 同じブランチのまとめ | サイドバーの「レーン」（レーンなしのとき） |
| サイドバーの「管理 › カテゴリ」 | カテゴリの絞り込みの見出しの ⚙ |
| レーンにしている軸の絞り込み | 出さない（例：レーンがカテゴリなら、カテゴリの絞り込みは出ない） |
