Codex デスクトップのスレッド画面（会話を主役に、ツール呼び出しは折りたたみ、編集は「N件のファイルを編集 +/−」で要約、下端に権限とモデルのチップ付きの入力欄）と、Claude デスクトップの Code タブ（セッション一覧・差分/ターミナル/プレビューのペイン・承認カード）を手本にした 8 案です。どれもクリックして触れます。色・余白は製品の ui/board.html のトークンをそのまま使い、ライト/ダークで確認できます。製品コードはまだ変更していません。

おすすめの進め方

1. 会話の見た目と入力欄（案 01 + 06 + 07）いまのカード詳細は「会話」「指示を送る」「属性」が同格のモジュールで、会話が小さく見えます。会話を主役にし、属性はヘッダーの 1 行と右の詳細パネル（i）へ。ツール呼び出しの折りたたみ、編集サマリー、入力欄のチップを入れます。既存データだけで実現でき、最も効果が大きい段階です。
2. ボード上のカード（案 03 + 04）状態の札を先頭の記号に、実行中の動きを光る 1 行に、差分を +/− に。標準を既定にし、現行とコンパクトは「レイアウトとテーマ」で選べるようにします。入力待ちのカードは、開かずに許可・返信できるようにします。
3. タスクカード（案 05）docs/card-model-research.md の案 A そのものです。説明・メモ・チェックリストを左、紐付いたセッションをスレッドの切り替えとして右に。子が 1 件なら自動で開きます。
4. 判断が要るもの（案 02・08）案 02 は差分・ターミナルの取得 API が新しく要ります。案 08 は「ページはボード 1 枚」の原則に触れるため、ボードの表示形式（リスト）として足すかを先に決める必要があります。

AGENTS.md の原則との関係

守っているもの ページはボード 1 枚 / 開くのはオーバーレイ（レイヤー 2）/ 色はトークン / 線のアイコン / すべての新操作にキーと ⌘K。
確認したいもの ① カードの構造は「札・タイトル・動き・点線の属性」の 4 段と定めているため、案 03 の標準は構造の改訂になる（docs/ui-components.md と AGENTS.md の更新が要る）。② 案 04 のインライン返信は、レイヤー 2 に上げずにボード面（レイヤー 1）で入力を受ける新しい扱い。③ 案 08 はボードの表示形式の追加。④ 新しいアイコン（undo diff mic stop send terminal branch pr shield など）は ui/icons.js の PIC に足す。
